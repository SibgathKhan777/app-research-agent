The agent

One Python pipeline, run per app. Search and page extraction go through the Composio SDK (Tavily toolkit); extraction is a hosted LLM run through a command-line client (Groq-hosted models are supported too). Every field must carry a source id and a verbatim quote, or say "unknown".

Discover

Official-domain search plus open-web search for five questions: overview, docs, auth, access, MCP. Each question keeps its own top results so one long reference page cannot crowd out the pricing page. Falls back to probing well-known official paths when search credits run out.

Read

Fetches pages directly, falling back to Composio's extract tool for JavaScript-heavy docs. Cached by URL so reruns are identical. The exact text the agent read is saved, so every quote can be re-checked.

Extract

BM25 picks the most relevant passages per topic. The model fills 10 fields, each with source, quote and confidence. Pass 1 is frozen with a checksum before any checking starts.

Verify

Quote must occur in the page; fields must not contradict each other; evidence links must be live and on the vendor domain; MCP claims are checked against the official registry; failed fields are re-derived. Anything unproven keeps its answer but is flagged.

Where a human was needed: Composio API key and Tavily credentials; deciding the schema and what counts as "buildable"; hand-labelling the 20-app sample against live vendor docs (done by the AI assistant, reading the docs, not by the agent under test); a person audited 5 of those labels at random. Sites that block bots (a few vendor help centres return 403) or render docs only in JavaScript needed a real browser to read.

Run it

Research one app live, end to end:

git clone 
cd app-research-agent
python -m venv .venv && . .venv/bin/activate && pip install -r requirements.txt
cp .env.example .env   # add COMPOSIO_API_KEY and TAVILY_API_KEY
python -m research.run --app notion

Or trigger it from GitHub: Actions → research-one → Run workflow, enter an app id, and the run prints the record with its evidence. Full 100-app run: python -m research.run --all --workers 5. Verification: python -m verification.auto_checks, python -m verification.repair, python -m verification.score.
